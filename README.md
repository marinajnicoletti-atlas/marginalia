# Marginália

Sua estante de grifos do Kindle. Importe o `My Clippings.txt`, veja seus livros em lombadas ou capas, sorteie trechos para reler, estude com IA e organize tudo.

**Seus dados ficam só no seu navegador**: nada é enviado para servidores.

## Como usar
1. Abra o site (GitHub Pages deste repositório).
2. Conecte o Kindle ao computador, abra a pasta `documents` e escolha `My Clippings.txt`.
3. Opcional: importe as capas pela pasta do Kindle, em Configurações → Importar capas e gêneros.
